Connect this browser to the board data

The board lives in the private repo . This page reads it through the GitHub API with a token that stays in this browser's local storage and goes only to api.github.com.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access: Only select repositories, pick the data repo.
  3. Repository permissions: Contents → Read-only. Generate the token.
